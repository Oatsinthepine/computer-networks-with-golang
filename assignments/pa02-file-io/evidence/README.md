## 已知差异与限制

- 当前 `PA2.go` 输出“行号 + 字符数 + 原文”；官方基础要求仅为“行号 + 原文”。字符数是个人扩展。
- 输入通过 `fmt.Scanf("%s %s", ...)` 读取，因此包含空格的完整绝对路径会被拆分；在作业目录中使用不含空格的相对文件名时正常。
- `bufio-read-file.go` 存在一次仅涉及 import 排序的 `gofmt` 提示，不影响运行结果。
- `examples/file_access/` 中包含多个 `main()`；各文件可独立运行，但未来执行全模块 `go test ./...` 前应按示例拆分子目录。
